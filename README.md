# DighaTour 🌊

A tourism website project focused on showcasing the coastal beauty of **Digha, West Bengal**. The website is designed to give visitors an overview of Digha and help them explore its attractions and experiences.

## 🌴 Project Overview

DighaTour is a frontend web development project with a clean, beach-inspired design. It features an aerial coastal hero section and a navigation bar to help visitors explore the website.

## 🛠️ Technologies Used

- **React.js** – Building the user interface using reusable components.
- **JavaScript (ES6+)** – Adding functionality and interactivity.
- **HTML5** – Structuring the web pages.
- **CSS3** – Styling, layouts, animations, and responsive design.
- **Bootstrap** 

## ✨ Features

- Beach-inspired homepage design.
- Hero section with an aerial coastal background image.
- Navigation bar for easy website navigation.
- Animated wave effect at the bottom of the hero section.
- Clean and simple user interface.
